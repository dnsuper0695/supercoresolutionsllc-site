Train BJJ — iOS Training Tracker

Live on App Store
SwiftUI Firebase Cloud Functions StoreKit 2 CloudKit HealthKit OpenAI GitHub Pages

Train BJJ is a purpose-built iOS app for Brazilian Jiu-Jitsu practitioners to log training sessions, track techniques, and monitor progress over time. Built from the ground up as a production iOS application, leveraging AI-accelerated development for implementation while personally handling all architecture, Firebase backend configuration, App Store submission, subscription setup, and community beta testing with offer codes.

What This Demonstrates

  • Full product lifecycle: concept, architecture, development, App Store approval, and post-launch iteration
  • Firebase backend implementation with real-time data, authentication, and cloud functions
  • StoreKit 2 subscription management with free trials, offer codes, and in-app purchase configuration
  • AI-powered features via OpenAI integration through Firebase Cloud Functions
  • Social features with feeds, training partner comparisons, and real-time notifications
  • App Store Connect navigation: review process, privacy policies, and TestFlight distribution

BrewRoute — Coffee Truck Mobile App

In Development
React Native Expo Firebase Toast POS Google Maps Cloud Functions

BrewRoute is a cross-platform mobile application being built for a local coffee truck business to manage customer ordering, route tracking, and engagement. The app integrates with Toast POS for seamless order management between the mobile experience and existing point-of-sale operations. Designed with a white-label SaaS architecture from day one, enabling future deployment to other mobile food service businesses.

What This Demonstrates

  • Client-facing project work with real business requirements and stakeholder collaboration
  • Cross-platform mobile development with React Native and Expo
  • Third-party POS integration with the Toast API
  • SaaS and white-label architecture thinking from the initial build
  • Multi-role system: shop owners, drivers, and customers with role-based access
  • Firebase backend for real-time ordering, route tracking, and data management
